Poker avatar images — source and license
=========================================

Most images in this folder are built from Google Noto Emoji SVGs
(https://github.com/googlefonts/noto-emoji, folder 2D/svg/), licensed under the
Apache License 2.0 (full text: LICENSE-Apache-2.0.txt, copied from 2D/svg/LICENSE).
The Noto font files (SIL OFL) are NOT used.

shark.svg is Google Noto Emoji 2D 🦈 U+1F988 (Apache 2.0), deep-blue circle,
paths and colours unchanged. It replaced the IconOven Stroke line-art shark
(LICENSE-MIT-iconoven.txt removed; that file is no longer used).
The original Noto fish.svg is unchanged.
The Lucide line-art fish (fish-line.svg) and LICENSE-ISC-lucide.txt were removed
2026-11-22: that icon was only added on this PR and never shipped to the live site.

robot.svg is OpenMoji color 🤖 U+1F916 (CC BY-SA 4.0, designed by OpenMoji – the
open-source emoji and icon project), light-blue circle, paths and colours
unchanged. Full license: LICENSE-CC-BY-SA-openmoji.txt.
  https://openmoji.org  https://github.com/hfg-gmuend/openmoji
  Source: https://raw.githubusercontent.com/hfg-gmuend/openmoji/master/color/svg/1F916.svg
  This file is a CC BY-SA 4.0 adaptation (original glyph on a circular background).
  Redistribution of this file must also be under CC BY-SA 4.0.

clown.svg is the red joker (joker_red) from Tek Eye SVG Playing Cards by
Daniel S. Fowler, dedicated to the public domain. Light-blue circle, card
artwork unchanged. The author asks that uses link to the introduction page
when practical: https://tekeye.uk/playing_cards/svg-playing-cards
  File: https://tekeye.uk/playing_cards/images/svg_playing_cards/fronts/joker_red.svg
These two replaced the Noto 2D robot and clown that were added earlier on this
PR and had never shipped to the live site. The Noto joker (joker.svg, A04 鬼牌)
is unchanged.


Modifications made to every file (2026-11-20):
- Adobe Illustrator metadata (i:aipgf, i:* attributes, DOCTYPE, comments) removed.
- Element ids prefixed with the file key.
- Placed on a 128x128 circle with one of two shared 2-colour vertical gradients: deep blue #5AB0FF→#1F5FD6, light blue #D8F0FF→#8EC4F8. (Red background #FF5A62→#C01828 was removed 2026-11-21 night; unused.)
- Emoji scaled per file so its visible size is about 78% of the circle diameter
  (100/128 px), centred, and kept inside radius 61.
2026-11-21: added spade, heart, diamond, club, and cat-calico in the same pipeline.
2026-11-21 evening: picker drops monkey (file kept so existing photoURLs still display). Backgrounds are only deep blue, light blue, and red, grouped in that order (7 / 8 / 4). Heart and diamond glyphs recolored to cream/white so they stay visible on red.
2026-11-21 23:15: drop frog and tiger from the picker (files kept in AVATAR_RETIRED). Replace Lucide Lab shark with IconOven Stroke shark (MIT) so the side view, triangular dorsal fin and tail read clearly at 390/60px. fish-line unchanged.
2026-11-21 night: added shark and fish-line (Lucide / Lucide Lab, ISC) at the end of the deep-blue group after the original Noto fish: 魚→鯊魚→線條魚. Cream #F3EAD2 strokes. Contrast vs the light top stop #5AB0FF is 1.93:1 on paper, but mid/bottom and 180–512px previews read clearly, so the shared deep-blue and cream were not changed.
2026-11-21 night: suit glyphs use poker colors (spade/club #1A1A1A / #2E2E2E; heart/diamond #B01C22 / #D7262E) on the light-blue background, listed at the end of the light-blue group. Red background retired.
