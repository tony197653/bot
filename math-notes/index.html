國中數學必背重點

點標題看公式，最後有附錄。

還沒有收藏，點公式旁的書籤就會出現在這裡。

絕對值與數線距離

數線上兩點 a、b 的距離 = |a−b|

用途　求兩數在數線上的距離。

指數律與科學記號

aᵐ × aⁿ = aᵐ⁺ⁿ

aᵐ ÷ aⁿ = aᵐ⁻ⁿ

(aᵐ)ⁿ = aᵐⁿ

(ab)ⁿ = aⁿbⁿ

a⁰ = 1（a ≠ 0）

a⁻ⁿ = 1/aⁿ（a ≠ 0）

科學記號a × 10ⁿ（1 ≤ a < 10）

用途　指數化簡、很大或很小的數。

比例式、正比、反比、連比

a:b = c:d

內項之積 = 外項之積

即b × c = a × d

a/b = c/d

正比y = kx（k ≠ 0）

反比xy = k（k ≠ 0）

連比a:b:c = ma:mb:mc

用途　比例、相似形題目；連比各項同乘一個不為 0 的數，比不變。

根式運算

√a × √b = √(ab)

√a ÷ √b = √(a/b)（a ≥ 0，b > 0）

(√a)² = a（a ≥ 0）

有理化1/√a = √a/a（a > 0）

用途　化簡根式；根號內的數 ≥ 0。

乘法公式與因式分解

(a+b)² = a² + 2ab + b²

(a−b)² = a² − 2ab + b²

a² − b² = (a+b)(a−b)

x² + bx + c：找兩數「和 = b、積 = c」

完全平方x² + 2ax + a² = (x+a)²

完全平方x² − 2ax + a² = (x−a)²

用途　展開、因式分解、會考代數題必用。

一元二次方程式公式解

ax² + bx + c = 0（a ≠ 0）

公式解x = (−b ± √(b² − 4ac)) / 2a

用途　不好因式分解時用公式解。

一元一次不等式

兩邊乘或除以負數，不等號反向

用途　解不等式時，兩邊同乘或同除負數要變號。

等差數列與等差級數

第 n 項aₙ = a₁ + (n−1)d

前 n 項和Sₙ = n(a₁ + aₙ)/2

前 n 項和Sₙ = n[2a₁ + (n−1)d]/2

用途　d 為公差；知道末項用第一式，不知道用第二式。

等比數列一般項

第 n 項aₙ = a₁rⁿ⁻¹

用途　r 為公比（後項 ÷ 前項）。

一次函數

y = ax + b

a：斜率；b：y 截距

斜率a = (y₂−y₁)/(x₂−x₁)（x₂ ≠ x₁；否則是鉛直線，斜率不存在）

用途　圖形是直線；斜率看傾斜，截距看與 y 軸交點。

二次函數的頂點、對稱軸與極值

y = ax²：頂點 (0, 0)

y = ax² + k：頂點 (0, k)

y = a(x−h)²：頂點 (h, 0)

y = a(x−h)² + k：頂點 (h, k)

對稱軸x = h（過頂點的鉛直線）

a > 0：開口向上，頂點最低

a < 0：開口向下，頂點最高

x 軸交點圖形與 x 軸交於 ax² + bx + c = 0 的根

用途　極值 = 頂點的 y 坐標（a > 0 最小值、a < 0 最大值）。

兩點距離

d = √[(x₂−x₁)² + (y₂−y₁)²]

用途　坐標平面上求兩點距離。

凸多邊形內角和

n 邊形(n−2) × 180°

用途　正 n 邊形每個內角 = (n−2) × 180° ÷ n。

平行線的角

同位角相等

內錯角相等

同側內角互補（和為 180°）

用途　兩線平行時，下列關係成立；也可用來判定兩線平行。

畢氏定理與特殊直角三角形

a² + b² = c²（c 為斜邊）

30°-60°-90°1 : √3 : 2

45°-45°-90°1 : 1 : √2

用途　邊比依序是短股、長股、斜邊。

正三角形的高與面積

高h = (√3/2)a

面積A = (√3/4)a²

用途　a 為邊長。

三角形中位線、梯形中位線

三角形中位線平行第三邊

三角形中位線 = ½ × 第三邊

梯形中位線平行兩底

梯形中位線 = (上底 + 下底)/2

用途　三角形連兩邊中點；梯形連兩腰中點。

三角形全等判定

SSS三組對應邊相等

SAS兩組對應邊及其夾角相等

ASA兩角及其夾邊相等

AAS兩角及其中一組對應邊相等

RHS兩直角三角形的斜邊與一股相等

用途　判定兩三角形全等。

相似形判定與平行線截比例線段

AA兩組對應角相等

SAS兩邊成比例，且夾角相等

SSS三邊成比例

平行線截比例三角形兩邊被平行於第三邊的線所截，對應線段成比例；反之，截線段成比例則兩線平行。

用途　中位線是特例，見上一項；面積比見下一項。

相似形的邊長比與面積比

邊長比= k

周長比= k

面積比= k²

順向算面積邊長比 a:b → 面積比 a²:b² （例如邊長 2 倍，面積變 4 倍）

逆向求邊長面積比 a²:b² → 邊長比 a:b （例如面積比 4:9，邊長比就是 2:3）

用途　面積比 = 邊長比的平方。

弧長與扇形面積

弧長(θ/360°)·2πr

扇形面積(θ/360°)·πr²

用途　θ 為圓心角；會考常出扇形題。

圓的性質

圓心角圓心角的度數 = 所對弧的度數

圓周角= ½ × 圓心角（同弧）

圓周角= ½ × 所對弧的度數

圓周角同圓或等圓中，同弧所對的圓周角相等

圓周角直徑所對的圓周角 = 90°

圓內接四邊形對角互補（兩組對角和都是 180°）

切線切線垂直於過切點的半徑

切線段等長從圓外一點作兩切線，切線段等長

弦心距圓心到弦的垂線平分該弦

弦心距d² + (弦長/2)² = r²

用途　d 為弦心距，r 為半徑。

三角形的外心、內心、重心

外心三邊垂直平分線的交點

外心到三頂點等距（外接圓圓心）

外心直角三角形：在斜邊中點

內心三內角平分線的交點

內心到三邊等距（內切圓圓心）

內心A = rs（s 為半周長）

內心r = (a + b − c)/2（直角）

重心三中線的交點

重心分中線 2 : 1（近頂點較長）

用途　直角三角形 a、b 為兩股，c 為斜邊。

直角柱與錐的體積、表面積

柱體積V = 底面積 × 高

柱表面積2 × 底面積 + 側面積

柱側面積底周長 × 高

圓錐表面積πr² + πrl

角錐表面積底面積 + 各側面面積

圓錐體積V = ⅓πr²h

角錐體積V = ⅓ × 底面積 × 高

用途　柱指直角柱；圓錐為直圓錐，l 為母線長；角錐為正角錐。錐體體積是同底等高柱體的 ⅓。

平均數、中位數、眾數、全距、四分位距與盒狀圖

平均數資料總和 ÷ 資料個數

加權平均Σ(分數×權重) ÷ Σ權重

中位數排序後取中間

中位數偶數筆 → 中間兩數平均

眾數出現最多的值

全距最大值 − 最小值

四分位距Q₃ − Q₁

五數最小、Q₁、中位數、Q₃、最大

用途　盒狀圖用這五個數畫出。

古典機率

P = 希望發生的情況數 ÷ 所有可能的情況數

每種情況發生的機會相同

0 ≤ P ≤ 1

用途　P = 0 不可能發生；P = 1 一定發生。
